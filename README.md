# Gestão Rádios SIRESP/ROB — CBSLeiria

Aplicação de gestão local-first com inventário, manutenção, backup JSON integral e sincronização controlada da listagem SIRESP para o Firebase.

Depois da primeira autenticação administrativa, a autorização Firebase fica guardada nesse navegador. As sincronizações seguintes necessitam apenas de confirmação. Use **Terminar sessão Firebase** para remover a autorização do dispositivo.

Consulte [GUIA_FIREBASE_GITHUB.md](GUIA_FIREBASE_GITHUB.md) antes da primeira publicação.
